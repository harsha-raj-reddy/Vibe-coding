# Vibe-coding: Personal Portfolio

A fast, responsive personal portfolio built with plain HTML, CSS and JavaScript. There's no build step and nothing to install.

## Features

- Sections for the hero, about, skills, projects, experience and contact
- Light and dark themes (follows your system, with a toggle that's remembered)
- Mobile-friendly navigation
- Animated gradient background, typing role, photo ring with floating tech logos, count-up stats, GPA rings and scroll reveals (all motion turned off when the visitor asks for reduced motion)

## Make it yours

All the content lives in **`data.js`**. Edit your name, role, about text, skills, projects, experience and contact links there, and the page updates.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Publish with GitHub Pages

1. On GitHub, go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then save.
3. The site will be live at the URL shown on that page within a minute or two.
